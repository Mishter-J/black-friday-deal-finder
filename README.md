DealHarbor is a static Black Friday and Cyber Monday deal finder. Every deal was checked at its store or in a deals source that names the store, and each one carries a verdict (new low, strong price, routine sale, or inflated list) with the evidence behind it. Search and filters by category, store, discount, and verdict work entirely offline from the files in `app/`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To browse the site itself, serve `app/` with any static file server and open `index.html`.
